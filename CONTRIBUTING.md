# Contributing to the Paranext Wiki

Thank you for your interest in contributing to the Paranext Wiki! This guide will help you make effective contributions.

## About This Repository

**Important**: This repository is exclusively for wiki documentation. It does **not** contain any code. All documentation is maintained in the [Wiki section](../../wiki) of this repository.

## How to Contribute

### Editing Existing Pages

1. Navigate to the [Wiki](../../wiki)
2. Find the page you want to edit
3. Click the "Edit" button (you may need appropriate permissions)
4. Make your changes using Markdown syntax
5. Add a brief description of your changes in the commit message
6. Click "Save Page"

### Creating New Pages

1. Go to the [Wiki](../../wiki)
2. Click "New Page" or link to a new page from an existing page
3. Write your content using Markdown
4. Save the page with a descriptive name

## Content Guidelines

### Style and Format

- **Use clear, concise language**: Write for a diverse audience with varying technical backgrounds
- **Use proper Markdown formatting**: Headers, lists, code blocks, links, etc.
- **Include examples**: Where applicable, provide examples to illustrate concepts
- **Structure content logically**: Use headers to organize information hierarchically

### Quality Standards

- **Accuracy**: Ensure all information is correct and up-to-date
- **Completeness**: Provide sufficient detail without overwhelming readers
- **Consistency**: Follow the style and terminology used in existing pages
- **Attribution**: Credit sources and link to relevant resources

### What to Document

- Project overviews and architecture
- User guides and tutorials
- API documentation and references
- Development guidelines and workflows
- FAQs and troubleshooting guides
- Glossaries and terminology

## Wiki Syntax

The wiki uses GitHub Flavored Markdown. Here are some useful elements:

```markdown

### Heading 3

**Bold text**
*Italic text*
`inline code`

- Bullet list
1. Numbered list

[Link text](url)
![Image alt text](image-url)

```code blocks```
```

## Getting Help

If you need help or have questions:

- [Open an issue](../../issues/new) in this repository
- Ask in Paranext community channels
- Review existing wiki pages for examples

## Code of Conduct

Please be respectful and constructive in all interactions. We're all here to improve documentation and help the community.

## Questions About Code?

Remember: This repository is for documentation only. For code-related questions or contributions, please visit the appropriate code repositories in the Paranext organization.
