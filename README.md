# Paranext Wiki Repository

This repository serves as the home for the **[Paranext Wiki](../../wiki)**.

## Purpose

This repository is **exclusively for hosting wiki documentation**. It does not contain any code or application files.

## Accessing the Wiki

To view or edit the wiki:
- **View the Wiki**: Click on the [Wiki tab](../../wiki) at the top of this repository
- **Edit the Wiki**: Navigate to any wiki page and click "Edit" (requires appropriate permissions)

## Contributing to the Wiki

We welcome contributions to improve our documentation! To contribute:

1. Navigate to the [Wiki section](../../wiki)
2. Either edit an existing page or create a new one
3. Follow the existing documentation style and structure
4. Provide clear, concise, and accurate information

## Questions or Issues?

If you have questions about the wiki content or notice any issues, please [open an issue](../../issues/new) in this repository.

---

**Note**: This repository intentionally contains no code. All development work happens in other Paranext organization repositories.
